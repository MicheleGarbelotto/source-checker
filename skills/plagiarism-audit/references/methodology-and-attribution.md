# Methodology and attribution

This skill is an independent, source-bounded implementation. Public documentation supplies limited definitions, vocabulary, and formula inspiration; the repository's calculation details, evidence rules, and classifications are independently specified in [metrics and rules](metrics-and-rules.md). The audit does not reproduce a vendor service, interface, model, database, or adjudication process.

## What the sources establish

- ORI places plagiarism within a formal research-misconduct definition and separately explains that using another writer's exact words requires both quotation marks and appropriate credit. Those boundaries motivate caution; they do not authorize this audit to adjudicate misconduct.
- iThenticate and Crossref describe an overall similarity percentage based on matching words relative to document words and emphasize that similarity is not itself plagiarism. The repository adds its own explicit analyzable-target denominator, global de-duplication rule, per-source calculation, and partial-corpus labels.
- The Copyleaks page accessed on 2026-09-23 documented three principal detection levels—identical, minor changes, and paraphrased or related meaning—and a feature named Cross-Language Detection. The repository adapts that vocabulary into its four canonical labels and applies them only after passage-level human verification.
- Turnitin currently documents four Match Groups based on detected citations and quotation marks and warns that detection can miss nonstandard or distant signals. The repository therefore treats the groups as descriptions of visible signals, not substantive attribution judgments.
- The SafeAssign page accessed on 2026-09-23 published the three numeric bands above. The repository deliberately changes their role to optional contextual review labels and rejects the source page's probability framing.

All sources above were checked individually on 2026-09-23. No vendor graphics, interface designs, long passages, or code are reproduced. Recheck the official page before describing a vendor's current behavior; if a term or band can no longer be verified, omit it rather than infer it from secondary material.
